3. ПРИМЕРЫ ИЗ ТЕКСТА

3.1. Производство настоек (f85r1.11)

pdar.ol.shdair.qopcheedy.dal.chdal.chor.shefshoro.raiin.dolor.aiin.opakam

Перевод: "Настой (dar) + масло (ol) + сырьё (shdair) → подъём (qopcheedy) → отстой (dal) → нагрев (chdal) → рециркуляция (raiin) → готовый продукт (opakam)"

Продукт: Лекарственная настойка на масляной основе

3.2. Производство эфирных масел (f47v.1)

psheot.cheor.cholsho.chopchy.sal

Перевод: "Подъём (psheot) цветочного сырья (cheor) → нагрев с перемешиванием (cholsho) → цветочная фильтрация (chopchy) → раствор (sal)"

Продукт: Эфирное масло из цветов

3.3. Производство мазей (f51r.15)

qokol.cheor.ckhal.s.or.aldy

Перевод: "Готовая основа (qokol) + цветочное сырьё (cheor) + обработка (ckhal) + раствор (s) + активная фаза (or) + кристаллизация (aldy)"

Продукт: Мазь с цветочным экстрактом

3.4. Производство духов (гипотетическая реконструкция)

Состав:
- Спирт-основа: qo-
- Эфирные масла: cheor + ol
- Настой трав: dar
- Фиксатор (смола): d-

Процесс:
1. Смешивание спирта с эфирными маслами
2. Добавление настоя трав
3. Добавление смолы-фиксатора
4. Отстаивание (qokeedy)
5. Фильтрация (pchedy)
6. Фасовка (qokain)

3.5. Производство ядов (f15v - вороний глаз)

poror.orshy.choiin.dtchan.opchordy

Перевод: "Вороний глаз (poror) → обработка (orshy) → нагрев (choiin) → конденсация (dtchan) → готовый яд (opchordy)"

Продукт: Концентрированный яд из вороньего глаза
Применение: Медицина (в малых дозах), отравление стрел

7. КЛЮЧЕВЫЕ ВЫВОДЫ

  1. Комплексное производство: Рукопись описывает не один продукт, а целую гамму продукции — от лекарств до духов и ядов.
  2. Универсальное оборудование: 9 башен используются для производства разных продуктов путём изменения сырья и технологических параметров.
  3. Три базовых компонента: Травы, спирт, вода — основа всего производства.
  4. Четыре типа производных: Смолы, масла, экстракты, эфирные масла — промежуточные продукты.
  5. Пять категорий продукции: Фармацевтика, яды, парфюмерия, косметика, техническая продукция.
  6. Сезонность: Сбор сырья привязан к фенологическому циклу растений (f68r1).
  7. Многоступенчатость: Каждый продукт проходит через несколько стадий обработки в разных башнях.

8. ЗАКЛЮЧЕНИЕ

Рукопись Войнича представляет собой универсальное технологическое пособие для комплексного фармацевтического, ядовитого и парфюмерного производства XV века. Это не просто "рецепты" — это полноценная промышленная технология с:

  • 🌸 Эфирные масла из ириса, кувшинки, шафрана
  • 🧴 Мази на основе масел с растительными экстрактами
