## 🎯 Краткое описание

Этот проект представляет собой **альтернативную теорию дешифровки рукописи Войнича**, основанную на гипотезе, что манускрипт является **учебником органической химии и фармацевтической технологии XV века**, написанным на профессиональном жаргоне монастырских алхимиков.

**Главная идея:** «Банный раздел» рукописи — это не сцены купания, а **схемы химических реакторов**, где обнажённые нимфы — это мнемонические образы молекул и фаз веществ.

---

## 🔬 Суть теории

### 🛁 «Баня» = Химический реактор

Страницы f75r–f84v, традиционно интерпретируемые как «бальный раздел» (сцены купания нимф в бассейнах), на самом деле описывают **технологические процессы органической химии**:

| Визуальный элемент | Химический смысл |
|--------------------|------------------|
| 🟢 Зелёные бассейны | Перегонные кубы / реакторы брожения |
| 🔵 Синие бассейны | Холодильники / конденсаторы |
| 🌈 Радужные арки | Дефлегматоры (флегмовый отбор) |
| 🔴 Трубы и каналы | Трубопроводы для пара и флегмы |
| ☁️ Облака пара | Летучие фракции (CO₂, спирты, эфиры) |
| ⭐ Звёзды | Этап выдержки / остывания |

### 👩 Нимфы = Молекулы (мнемонический приём)

Обнажённые женщины в бассейнах — это **аллегории молекул и фаз веществ**:

- **Нимфа, лезущая в трубу** = летучая фракция, переходящая в пар
- **Нимфа в синем пятне у трубы** = водная фаза, идущая на слив (декантация)
- **Нимфы в зелёном «болоте»** = многокомпонентная реакционная масса
- **Нимфа, остывающая под звёздами** = продукт, проходящий этап выдержки
- **11 нимф в котле** = сложная многокомпонентная смесь

**Почему голые?** Это **мнемонический приём** для обучения подмастерьев (16–20 лет) в монастырском скриптории. В эпоху, когда книги стоили состояния, яркий образ запоминался лучше сухого текста.

### 🏛️ Авторство: монастырский скрипторий

Гипотеза предполагает, что рукопись создана **коллективом монахов-алхимиков** (возможно, францисканцев), обладавших:
- Доступом к редким растениям (включая экзотические из Нового Света)
- Лабораториями для дистилляции и экстракции
- Традицией шифрования знаний от инквизиции
- Сетью монастырей для передачи рецептов

## 💡 Ключевые открытия

### 1. Агглютинативная морфология EVA

Язык Войнича имеет
Каждый элемент несёт **конкретный физико-химический смысл**.

### 2. Префиксы = физические действия

| Префикс | Значение | Химический смысл |
|---------|----------|------------------|
| `qo-` | твёрдое / сухое | Прокаливание, кальцинация |
| `8-` | жидкость / объём | Раствор, кипящая жидкость |
| `9-` | газ / пар | Летучая фракция |
| `l-` | холод | Охлаждение, конденсация |
| `r-` | возврат | Рефлюкс, рециклинг |
| `p-` | давление / пар | Дистилляция, подъём |
| `ct-` | осадок | Концентрат, гуща |
| `f-` | фильтрация | Очистка, осаждение |

### 3. Галлоусы = катализаторы

| Галлоус | Значение |
|---------|----------|
| `k` | щёлочь / зола (омыление) |
| `g` | кислота |
| `t` | высокая температура |

### 4. Ключевые слова с фиксированным переводом

| EVA слово | Перевод | Химический смысл |
|-----------|---------|------------------|
| `qokey` | отстоять / довести до готовности | Выдержка, завершение процесса |
| `qokain` | готовый продукт | Финальная субстанция |
| `qoteody` | коагулят | Осадок после нагрева гетерогенной системы |
| `olkeedy` | алкидный эфир | Омыленное масло (омыление + этерификация) |
| `daiin` | сырьё | Растительная масса |
| `cthy` | горячий студень | Конденсат |
| `cthod` | остывший осадок | Кубовый остаток |
| `otal` | труба / канал | Отбор по пару |
| `8chol` | точка кипения фракции | Относительный нагрев |

## 🔍 Примеры расшифровки

### 📄 Страница f83r — Ректификационная колонна

**Визуал:** Система бассейнов, арок, труб и нимф — классический самогонный аппарат с дефлегматором.

**Реальный EVA-текст (фрагмент):** чёткую **морфологическую структуру**:

**Расшифровка:**
> *"Масляный эфир (`solkeedy`) нагреть до кипения (`qoteedy`), повторить (`qokeey`), завершить (`qokedy`), раствор (`sol`) обработать, нагреть до кипения (`qokedy`), слить воду (`saiin`)"*

**Химический процесс:** Фракционная дистилляция с рефлюксом — получение спирта-ректификата или алкидных смол.

### 📄 Страница f82v — Многокомпонентный реактор

**Визуал:** 11 нимф в зелёном «болоте», две нимфы лезут в трубы, одна нимфа в синем пятне у сливной трубы.

**Интерпретация:**
- **11 нимф внизу** = вода + сахар + дрожжи + растительное сырьё (многокомпонентная брага)
- **Два облака пара** = CO₂ (брожение) + пары спиртов/ацетонов (испарение)
- **Две нимфы в трубах** = летучие фракции на перегрев (уксусный ангидрид)
- **Нимфа в синем пятне** = слив водной фазы (декантация)

### 📄 Страница f84r — Синтез алкидов

**Ключевое слово:** `olkeedy` — алкидный эфир, полученный омылением масла щёлочью.

Это **реакция этерификации**, известная в современной химии как синтез алкидных смол — основа лаков и олифы для икон.

## 🧬 Морфологическая матрица

Полная матрица реализована в классе `MorphologyMatrix` файла `voynich_analyzer.py`.

**Комбинаторика:**
- ~10 корней × 8 префиксов × 8 суффиксов × 5 галлоусов = **3 200 базовых терминов**
- С учётом вариаций — **~7 500 уникальных словоформ**, что совпадает со статистикой рукописи.

⚠️ Ограничения и честные признания
Это гипотеза, а не доказанная дешифровка. Мы построили внутренне непротиворечивую модель, но без полного словаря-ключа пословный перевод невозможен.
Нет доступа к оригиналу. Анализ проводится по EVA-транскрипциям, которые могут содержать ошибки.
Хронологическая проблема. Пергамент датируется 1404–1438 гг., но некоторые растения и процессы могут указывать на более поздний текст.
Фонетика неизвестна. Мы определяем функции слов, но не их точное звучание.
🎭 Забавные совпадения
qokain = «готовый продукт» в нашей модели. Фонетически — «кокаин». Инки жевали коку со щёлочью (зола киноа) — это та самая щелочная экстракция, которую описывает qo-k-ain! 😄
Францисканцы в Перу появились в 1530-х, а пергамент — XV век. Возможное решение: текст записан позже на старом пергаменте.
Современные самогонщики с их спорами о «дефлегматоре и отборе по пару» фактически повторяют технологии, описанные в Войниче 600 лет назад.
